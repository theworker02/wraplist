# wraplist

Wrap identifiers and list tokens for idempotent workflows.

**Site:** https://theworker02.github.io/wraplist/

## Install / run

```bash
git clone https://github.com/theworker02/wraplist.git
cd wraplist
node src/cli.js
node --test
```
